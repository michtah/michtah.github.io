Large Numbers: Main

Welcome to the large numbers website. This is where I will be uploading my explanation of large numbers and how they work. The purpose of this website is to showcase the interesting mathematics behind this topic. The thing is, large number discoveries tend to lead to a lot of discoveries in set theory, logic, model theory, and ordinal analysis.

This page is only the first page. The goal of this page is to be the first page and go into a little bit about what we're going to be talking about. The structure of this page is going to be a little bit different compared to how it is in most other large number websites. The start is going to be pretty similiar: we'll look at some traditional large numbers (googol, googolplex, skewes' number, among others), and some traditional constructions (up arrows, hyperoperators, array notations).

However, after these basic ideas, the goal is to dive deep into set theory and ordinal analysis, which is the true heart of this topic. To describe it shortly: if you can make large ordinals, you can make large numbers, and usually vice versa. The next section is the table of contents.
