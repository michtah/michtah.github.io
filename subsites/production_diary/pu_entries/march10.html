March 10th: Re-making Large Numbers and Fighting User Forms

Hello. You are here. In my production diary.

This entry is dedicated to the new Large Numbers section I added to my website. It is going to be an extra addition to my website dedicated as an explainer for large numbes. I also added a contact section into my portfolio, so that others may send me messages if they so please.

Large Numbers is Live!

Yes, it's true! It comes in a nice shade of purple too. For now it's the introduction and table of contents only, but slowly I will start populating it with various entries. This was an interesting project because it got me thinking about how I should keep my CSS consistent. I decided that it is for the better if I come up with some consistent color terminology for websites. That way I don't have to constantly edit every single field to get a new css file.

Beyond that, I had to come up with some new shades of purple to make everything look good. One thing about the actual original purple (no matter how eternal it is) is that it's a bit dull and doesn't read well on titles and bodies of text. Beyond that not else much to say. Hope you enjoy my website.

Creating a User Form (scary)

I haven't really been the most comfortable having any interactive elements in my website, nevermind a whole form where users can send me text, but I think I managed to do it while keeping my worries at check. So hooray!

While for now I don't really understand what my javaScript is doing, soon enough I will, hopefully. I am slowly learning javaScript after all :(

Once again, not much to say. It was interesting but I want to work on more interesting projects.
