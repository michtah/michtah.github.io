March 23rd: Remaking Michtah... again

This production diary is a lesson in not testing your ideas at a small scale before implementing them.

I showed the last version of this website to my lecturer. I was quite proud of it, and the theming and glows were my personal touch. I like the look, and it reminds me of my favourite web game Antimatter Dimensions.

When I showed it to him, he was quite happy with the look and user interface, but he struggled to read some of the text because it was too small, and he couldn't read the glowing text because it blended with the background. I understood his concerns, but also was quite sad since I really did like the look of the website. I felt a bit conflicted for a bit about what to do.

Then, I thought, why not just add options for this website? I don't see why that's not an option. So I started adding it and I thought I knew what I was doing so I just did it to the whole website without care. However, turns out, the way I had been doing it was not possible with the UI elements I wanted to add. However, it was too late. I had already added it all and my website was pretty broken. I could try reverting it back but I really wanted to add the features that were missing.

With that came this third rewrite of the website. The one that you're looking at right now. This also came with more refining of the features I had added to the website prior. First of all, the buttons of the user interface felt kind of useless when the actual location text at the top was a readily available navigation tool. I got rid of the buttons. Now if you want to head back to main you can just click that part of the location info and it will take you there. Furthermore, I streamlined the appearance of the website and got rid of some of the flashier effects. Though I quite like the blurring effects, so I kept them.

However, I did keep my lecturer's concern in mind. So besides the location bar, you'll see two options. One switches between a dark and a light mode, and the other toggles the glowing effect. Hopefully these additions will aid more users when using my website.
